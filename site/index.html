ANDROID • EXPERIMENTAL POC

Bluetooth Alert POC

Experimental Android app testing whether permitted notification text can be presented as media metadata on compatible vehicle Bluetooth displays.

Download latest APK

How to test

  1. Download and install the latest APK.
  2. Pair your Android phone with the car normally and select Bluetooth Audio.
  3. Open the app and grant Notification Access.
  4. Press Send test metadata to car.

POC only: compatibility varies by phone, Android version, vehicle, head unit and Bluetooth AVRCP support. This app does not pair with the car itself.

Privacy: the current POC is designed to pass notification metadata through memory without intentionally persisting notification text to disk, analytics or a server.
